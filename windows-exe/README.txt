Nancy HR - HR Management System (Windows)
=========================================

HOW TO START
  Double-click NancyHR.exe.

  The first time, Windows may show "Windows protected your PC".
  Click "More info", then "Run anyway". (This appears because the
  program is not signed by a paid certificate; it is safe to run.)

KEEP THESE TOGETHER IN ONE FOLDER
  NancyHR.exe        - the program
  logo.jpeg          - the logo shown on the Dashboard
  hr_management.db   - all your records (created the first time you run it)
  photos\            - employee photos (created when you add the first photo)

  Put the folder somewhere permanent, e.g. Documents\NancyHR - not in
  Downloads, and not inside the zip file. Run it from the unzipped folder.

EXPORT TO EXCEL
  Click "Export to Excel" on the Dashboard (or on the Reports tab) and
  choose where to save. The Excel file is a copy of the records at that
  moment - changes made in Excel do not go back into the program.
  It contains personal details (Ghana Card, SSNIT numbers), so store and
  share it carefully.

BACKUPS
  Copy hr_management.db and the photos folder to a USB stick or cloud
  storage regularly. To move to a new computer, copy the whole folder.

UPDATING TO A NEW VERSION
  Replace only NancyHR.exe. Keep hr_management.db and photos\ - they hold
  your data.
